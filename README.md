# 🍳 IngrediScale | Smart Recipe Scaler

A dynamic, user-friendly web application that helps users scale cooking ingredient quantities based on desired servings. Built with **pure Vanilla JavaScript**, it features custom unit selection, precision ratio calculations, and persistent recipe storage.

---

## 🚀 Live Demo
Check out the live application: **[IngrediScale Live Demo](https://.HabibaSherif77github.io/RecipeScaler/)**

---

## ✨ Key Features

- ⚖️ **Dynamic Portion Scaling:** Automatically recalculates all ingredient amounts instantly based on target servings.
- 📐 **Multi-Unit Support:** Supports multiple units of measurement (`g`, `kg`, `ml`, `l`, `cups`, `tbsp`, `tsp`, `pieces`).
- 💾 **Persistent Storage (LocalStorage):** Save your favorite recipes and load them anytime without losing data on page refresh.
- ➕ **Flexible Row Management:** Add or remove ingredient fields dynamically with a single click.
- 📱 **Fully Responsive:** Clean UI optimized for desktop and mobile screens.

---

## 🛠️ Tech Stack & Concepts Applied

- **HTML5:** Semantic structure and accessible input forms.
- **CSS3:** Custom layout design, Flexbox, transitions, and media queries.
- **JavaScript (ES6+):**
  - **DOM Manipulation:** Dynamic creation, removal, and updates of DOM elements.
  - **LocalStorage API:** Full CRUD-like logic to save, load, and delete recipe JSON data.
  - **Event Handling:** Delegation for dynamic inputs and control flow.
